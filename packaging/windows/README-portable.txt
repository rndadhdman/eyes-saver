Eyes Saver for Windows (portable)
=================================

Run EyesSaver.exe. Nothing is installed.

Settings are kept in the "data" folder next to the program, so the whole folder can live on a
USB stick. Delete the "data" folder to keep settings in %LOCALAPPDATA%\EyesSaver instead.

Shortcuts: Ctrl+Alt+F9 pauses or resumes, Ctrl+Alt+PgUp / PgDn change the strength.
Command line: EyesSaver.exe --toggle | --pause | --resume | --stronger | --weaker | --quit

"Start with Windows" in the app adds a per-user startup entry pointing at this copy.
